# ShiftSetu — LedgerLess Smart Workforce Management

A modern, high-performance React + TypeScript + Vite web application styled with Tailwind CSS and Lucide icons.

## Features

- **LedgerLess Architecture:** Real-time digital shifts and attendance records, eliminating paper registries and spreadsheet chaos.
- **Smart Shift Roster:** Automated shift planning and allocation.
- **Biometric & Geo-Verification:** Site-specific check-ins and audit-proof timestamps.
- **Live Command Center:** Real-time attendance pulse and metrics.
- **Instant Payroll Readiness:** Automatic wage and overtime calculations.

## Getting Started

### Prerequisites

You need **Node.js** (v18 or later recommended) and **npm** installed on your system.
Download from: [https://nodejs.org/](https://nodejs.org/)

### Installation & Running

1. Open PowerShell / Command Prompt and navigate to this folder:
   ```bash
   cd ShiftSetu
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```

4. Open your browser at:
   [http://localhost:5173](http://localhost:5173)
